# Related Work

| Work | Citation | Used for |
|---|---|---|
| Reward Centering | Naik, Wan, Tomar, Sutton — arXiv:2405.09999 (RLC 2024) | Core theory and equations for simple/value-based centering; the Q-learning convergence proof DQN implementation follows directly. |
| Improving RL with Biologically Motivated Continuous State Representations | Bartlett, Simone, Dumont, Furlong, Eliasmith, Orchard, Stewart — ICCM 2022 | Original HexSSP + RatBox/CartPole results this project extends. Prior findings being re-validated on the new codebase. |
| Bellman Error Centering | Chen, Gong, Yang, Wang — arXiv:2502.03104 (2025) | More precise theoretical framing of value-based centering (it's Bellman-error centering, not reward centering); stronger convergence results (linear FA, on/off-policy); used as the basis for the A2C/PPO centering implementation instead of the original paper's raw equations. |
| Average-Reward Soft Actor-Critic (ASAC) | Adamczyk, Makarenko, Tiomkin, Kulkarni — arXiv:2501.09080 (2025) | Related but distinct centering mechanism for SAC specifically; reference point if/when SAC is added. Their reported ~3000 GPU-hours is a compute-scale calibration, not a method to copy directly. |
| Loss of Plasticity in Continual Deep RL | Alberta/Amii lineage — arXiv:2303.07507 | Motivates the plasticity-monitoring diagnostic in continuing-task (Stage 3) runs. Not a swept axis in this project. |
| mjlab | Zakka, Liao, Yi, Le Lay, Sreenath, Abbeel — arXiv:2601.22074 (2026), UC Berkeley | The GPU-accelerated robotics simulation framework this project's Stage 2/3 work is built on. |
| RSL-RL | Schwarke, Mittal, Rudin, Hoeller, Hutter — arXiv:2509.10771 (2025), ETH Zurich/NVIDIA | The training library mjlab uses (PPO + distillation); `PPO.compute_returns` is where the centering patch lives. |
| Isaac Lab | Mittal et al. — arXiv:2511.04831 (2025), NVIDIA | Considered and not chosen as the primary robotics stack (heavier GPU/setup requirements than mjlab); mjlab's manager-based API is itself adapted from Isaac Lab's. |
| MuJoCo Playground | Zakka et al. — arXiv:2502.08844 (2025), Berkeley/DeepMind | Alternative GPU-native robot-learning framework considered (JAX-based); not chosen, mjlab preferred for its PyTorch-native interface. |
| Automatic Hyperparameter Tuning — A Visual Guide / In Practice | Raffin — [Part 1](https://araffin.github.io/post/hyperparam-tuning/) (2023), [Part 2](https://araffin.github.io/post/optuna/) (2025) | The hyperparameter-search methodology this project's Optuna scripts directly implement — search space/objective/callback structure, `TPESampler`+`MedianPruner` configuration, single-seed-during-search + post-hoc top-trial re-evaluation. See `02-experimental-design.md`. |
| Hyperparameters in Reinforcement Learning and How To Tune Them | Eimer, Lindauer, Raffin — arXiv:2306.01324 (ICML 2023) | Empirical basis for keeping seed count low (~≤3) during active search — more tuning seeds was found to make HPO harder without reliably better held-out performance — and for the fairness argument against reusing one config's tuned hyperparameters for another. |
| How Many Random Seeds? Statistical Power Analysis in Deep RL Experiments | Colas, Sigaud, Oudeyer — arXiv:1806.08295 (2018) | Basis for the ≥20-seed floor used for each cell's final reported result (post-search, no more tuning happening) — a distinct concern from search-time seed count. |
| Deep Reinforcement Learning That Matters | Henderson, Islam, Bachman, Pineau, Precup, Meger — arXiv:1709.06560 (2017) | Documents that most published RL results historically used ≤5 seeds; motivates moving this project's final-evaluation seed count up from its earlier 5-seed convention. |
| An Empirical Study of Deep RL in Continuing Tasks | Wan, Korenkevych, Zhu — arXiv:2501.06937 (2025, Meta) | The continuing-task testbed suite (MuJoCo + Atari, three reset scenarios) and the largest published centering evaluation (DDPG/TD3/SAC/PPO/DQN; TD-based vs moving-average vs reference-state centering). Open code: `facebookresearch/DeepRL-continuing-tasks`. Also the source of the wrapped-angle effect (347%-1608%) that motivates a periodic encoder arm. Occupies the "does centering generalise in deep RL" slot — do not re-run it; extend it with the encoder axis. |
| Extending Differential TD Methods for Episodic Problems | De Asis, Elsayed, He — arXiv:2605.04368 (2026) | Termination-corrected differential TD: proves policy ordering is preserved with termination, extending reward centering to episodic problems, and shows sample-efficiency gains. Supersedes the "centering is not applicable to episodic tasks" framing in decision-log entry 17. |
| On the Power and Limitations of Random Features for Understanding Neural Networks | Yehudai & Shamir — arXiv:1904.00687 (NeurIPS 2019) | Hard limit on a fixed random feature map with a linear readout; SSP is a random-feature map. See `08-...md` section 1. |
| Random Fourier Features for Kernel Ridge Regression | Avron et al. — PMLR v70 (ICML 2017) | Feature-count vs error bounds for random Fourier features — why "high-dimensional" is a cost as well as a capacity. |
| Linearized two-layers NN in high dimension / Limitations of Lazy Training / When Do NNs Outperform Kernel Methods? | Ghorbani, Mei, Misiakiewicz, Montanari — arXiv:1904.12191, arXiv:1906.08899, arXiv:2006.13409 | The curse of dimensionality in the kernel/lazy regime, and when the learned regime escapes it. |
| The Utility of Sparse Representations for Control in RL | Liu, Kumaraswamy, Le, White — arXiv:1811.06626 (AAAI 2019) | Sparsity/locality improves control; dense representations interfere. |
| Measuring and Mitigating Interference in RL | Liu, Wang, Tao, Javed, White, White — PMLR v232 (CoLLAs 2023) | The interference measure to implement (docs/08 H1); CartPole experiments; tile coding used as the explicit no-interference contrast. |
| Capacity Analysis of Vector Symbolic Architectures | Clarkson, Ubaru, Yang — arXiv:2301.10352 (2023) | Bounded VSA representation capacity; crosstalk as a sketching/Bloom-filter error floor. |
| Vector Symbolic Policy Gradient | Masukawa et al. — arXiv:2608.18404 (2026) | VSA on the action side (action hypervectors, advantage-weighted bundling, bit-flip robustness). Adjacent, not the same question as a structured state encoder. |
| Simulating and Predicting Dynamical Systems With Spatial Semantic Pointers | Komer, Dumont, Eliasmith et al. — Neural Computation 33(8), 2021 | SSP's demonstrated strengths are dynamical and spatial; useful for scoping where SSP should and should not be expected to help. |
| Show Your Work: Improved Reporting of Experimental Results | Dodge, Gururangan, Card, Schwartz, Smith — EMNLP 2019 | Budget-conditional reporting: expected-max-performance vs budget; why a `max`-of-N reference number is not a measurement, and why bound pressure is a reporting problem rather than a re-search problem. |
| The Machine Learning Reproducibility Checklist (v2.0) | Pineau — 2020 | The reporting items a baseline must carry (hyperparameter ranges, selection method and criterion, number of runs) — the items our legacy A2C reference fails. |
